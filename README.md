# 词隐 WordNook

高三英语背单词网页应用：以「熟词僻义」特色词库 + 间隔复习算法为核心的每日 10 分钟学习闭环。

## 功能

- **今日任务**：打开即见今日到期复习 + 新词数量，一键开始学习
- **卡片学习**：点击翻面看释义，三档自评（认识 / 模糊 / 不认识）驱动间隔复习
- **间隔复习**：认识 → 4/7/15/30 天递进间隔；模糊 → 明天再见；不认识 → 本会话内 3 张卡片后重出 + 明天优先复习
- **熟词僻义词库**：139 个高考高频熟词僻义（如 address=处理、school=学派），每个词配高考风格例句
- **考纲高频词库**：99 个考纲核心动词与形容词
- **统计面板**：连续打卡、已掌握/复习中、近 14 天学习量、薄弱词 TOP 10
- **本地存储**：进度保存在浏览器 localStorage，无需注册登录

## 技术栈

React 19 + TypeScript + Vite + Tailwind CSS + Fraunces 字体

## 本地运行

```bash
npm install
npm run dev
```

构建：`npm run build` → `dist/`

## 数据与隐私

所有学习数据仅保存在当前浏览器的 localStorage 中，不上传任何服务器；清除浏览器数据会丢失进度。
